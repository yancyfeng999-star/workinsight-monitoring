# 决策登记（Decision Register）

> 版本：v1.0 · 日期：2026-08-10
> 状态取值：`confirmed`（用户明确授权）| `working_assumption`（工程默认，待正式确认）|
> `unconfirmed`（未确认，开发可用合成数据，不得当生产决定）。
> 本登记按《继续开发执行计划-审查整改到完整交付-v1.0.md》要求建立，纠正此前
> “15 项全部确认”的不实表述。

## 已确认（用户明确授权）

| 决策 | 内容 | 证据/影响 |
| --- | --- | --- |
| 公司内部使用 | 系统仅用于公司内部、自有或统一受管办公电脑 | 排除 BYOD、外部 SaaS、多租户 |
| 分析全部在监控端 | 分类、统计、规则、大模型只存在于监控端；Agent/扩展无业务分析 | 架构硬边界，CI/产物扫描强制 |
| 默认后台自启动 | 被监控端完成首次配置后默认随用户登录后台启动，不弹主窗口 | 登录启动注册为默认行为 |

## Working Assumption（工程默认值，正式部署前确认）

| # | 决策点 | 默认值 | 影响 |
| --- | --- | --- | --- |
| 1 | 首要用途 | 员工效率与工作节奏分析 | 不用于工时核算/审计为主 |
| 2 | 设备-员工映射 | IT 提供清单，管理员手动映射 | 无 AD/SCIM 自动同步 |
| 3 | 监控端部署 | 公司管理员 Mac 本机 | 单机部署；迁移内网服务器需评估 |
| 4 | 明细 vs 汇总 | 两者都要；明细需授权+审计 | RBAC 个人明细 Scope |
| 5 | 窗口标题 | 默认关；策略开启+辅助功能权限时采集并脱敏 | 标题是敏感字段 |
| 6 | 浏览数据精度 | 仅 registrable domain | query/path 永不保留 |
| 7 | 暂停权 | 仅管理员远程控制 | 员工无暂停入口；暂停如实上报 |
| 9 | 永不记录清单 | 密码管理器、银行/支付、个人邮箱、宗教/政府身份、localhost/内网页 | 本地+服务端双层拦截 |
| 10 | 模型 Provider | DeepSeek API | 密钥只在 Worker 环境；可切换 |
| 11 | AI 报告受众 | 仅公司管理员 | Manager/Auditor/Operator 默认不可读 |
| 12 | SSO/MDM | 均无 | 内置账号+手动分发 |
| 13 | 最低 OS | macOS 13+ / Windows 11 | Win10 LTSC 单列评估 |

## 变更规则

- 任何决策从 `unconfirmed` 变 `confirmed` 需用户当次明确授权并记录证据。
- 未确认事项不阻塞使用合成数据开发；不得写入任何文档声称其为用户授权的生产决定。
