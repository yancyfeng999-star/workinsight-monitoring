# 数据采集矩阵（Data Collection Matrix）

> 版本：v1.0 · 对应产品合同 v1.0

## 采集矩阵

| 数据 | 默认 | 精度/示例 | 本地处理 | 服务端用途 | 默认保留 |
| --- | --- | --- | --- | --- | --- |
| 设备身份 | 采集 | 随机 `device_id`、OS、Agent 版本 | 不上传硬盘序列号等强标识 | 注册、健康、版本 | 设备存续期 + 30 天 |
| 用户身份 | 采集 | 公司内 `subject_id` | 与本机用户名分离；监控端受控映射 | 权限与员工数据 | 在职/授权期 |
| 前台应用 | 采集 | bundle id / process id / 产品名 | 规范化、敏感 App 黑名单 | 使用时长分类 | 原始 30 天，聚合 365 天（可配，上限 99 年） |
| 窗口标题 | **默认不采** | 最长 256 字符 | 策略开启时采集；邮箱、文档名、账号等模式脱敏；敏感 App 可整段丢弃 | 精细分类与本人时间线 | 原始 7–30 天 |
| 浏览器域名 | 采集 | `registrable_domain`，如 `example.com` | 去协议、端口、path、query、fragment | 网站分类与时长 | 原始 30 天，聚合 365 天（可配） |
| 完整 URL | 默认不采 | path 永不默认保留；query/fragment 永不保留 | 本地规则过滤 | 特殊业务分析（白名单试验） | 默认 0 天 |
| 标签页标题 | 默认受限 | 最长 256 字符 | 敏感规则和 PII 脱敏 | 分类/个人查看 | 原始 7–30 天 |
| 空闲状态 | 采集 | active/idle/locked | 不采具体按键或鼠标位置 | 排除离席时间 | 30 天后只留聚合 |
| 设备健康 | 采集 | 队列深度、最后上传、权限状态、CPU/内存分位数 | 日志脱敏 | 运维 | 30–90 天 |
| 私密/无痕状态 | 只用于丢弃 | true 时不形成活动事件 | 本地立即丢弃 | 不上传 | 0 天 |
| 截图/录屏/键盘/剪贴板/正文 | 不采 | — | — | — | 0 天 |

## 本地永不记录清单（v1.0 已确认）

密码管理器、银行/支付、个人邮箱、宗教/政府身份服务、`localhost`/内网管理页面。
管理员可以增加屏蔽规则，但不能远程取消“私密模式永不记录”的硬规则。

## 本地敏感过滤顺序

```text
系统/浏览器事件
  → 私密模式判断（命中即丢弃）
  → 敏感应用/域名整段屏蔽
  → URL 规范化，只取 registrable domain
  → 标题长度限制（≤256）
  → 本地 PII/密钥/令牌/邮箱模式脱敏
  → 组织白名单/黑名单策略
  → 相邻事件合并
  → 加密本地队列
  → 上传
```

## 禁止采集（任何情况下）

截图、录屏、键盘内容、剪贴板、网页正文/DOM/表单/密码/Cookie、邮件与聊天正文、
文件内容、网络抓包内容、私密浏览事件、摄像头、麦克风。

## 保留期管理

- 默认：原始事件 30 天，聚合 365 天；窗口/标签页标题 7–30 天。
- 管理员可在监控端按组织/团队配置；磁盘未满时可放宽，**硬上限 99 年**。
- 后台设置必须有明确上限，不能“无限期”无界存储；超过保留期的数据不可通过
  缓存、聚合、Insight 或搜索再次出现。
- 删除采用可验证异步作业，完成后写删除证明，不保留被删除内容本身。
