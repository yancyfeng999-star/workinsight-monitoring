# 数据流（Data Flow）

> 版本：v1.0

## 端到端数据流

```text
[OS 前台应用事件] ─┐
                    ├─→ 采集策略过滤（私密/敏感/白名单）
[浏览器活动标签页] ─┘        │
                            ▼
                    规范化（domain-only、标题截断、PII 脱敏）
                            │
                            ▼
                    Segmenter 合并相邻事件（≤4h 切段）
                            │
                            ▼
                    SQLite 加密队列（WAL，上限 72h/100MB）
                            │
                            ▼
                    Uploader：gzip 批量 → TLS → API
                            │
                            ▼
                    Schema/幂等校验 → activity_segments / activity_events_raw
                            │
                            ▼
                    Worker：日聚合 → 分类（规则优先）→ 规则事实
                            │
                            ▼
                    （Phase 3）DeepSeek Insight（脱敏聚合输入）
                            │
                            ▼
                    Web Console：团队汇总 / 个人明细（授权+审计）/ AI 报告
```

## 关键不变量

1. 事件在 Agent 端先过滤后入队：禁止字段在写盘前被丢弃。
2. ACK 后按批次删除本地队列，不用“发出即删除”。
3. 服务端重新计算 duration，不信任客户端。
4. 私密模式事件永不入本地队列，也永不达服务端。
5. 业务分类、聚合、规则、AI 只存在于监控端 Worker。
6. 模型输入 = 匿名 subject + 日期范围 + 分类分钟数 + 聚合指标 + 规则事实；不含
   真实姓名、邮箱、完整 URL、query、原始标题、设备密钥、访问令牌。
7. 时钟回拨/时区/DST 不修改 UTC 事实时间，客户端时区仅用于展示。
8. 健康事件（权限、队列、版本、自启动状态）独立上报，与活动数据隔离存储。

## 缺口语义

- 掉线、权限丢失、自启动被关、队列满丢弃 → 上报健康状态并标记数据缺口。
- 分析层必须把缺口当缺口，不把缺失解释为低使用。
