# 访问矩阵（Access Matrix）

> 版本：v1.0

## 角色与能力

| 能力 | Manager | Company Admin | Internal Auditor | System Operator |
| --- | --- | --- | --- | --- |
| 团队汇总 | 授权团队 | 组织汇总 | 必要汇总 | 仅健康数据 |
| 员工明细 | 授权团队 | 按内部权限（需审计） | 按审计范围 | 否 |
| 策略管理 | 否 | 是 | 否 | 基础运维 |
| 导出 | 汇总 | 受控 | 只读 | 否 |
| 审计日志 | 自己访问记录 | 管理操作 | 是 | 运维审计 |
| AI 报告 | 否（v1.0：仅公司管理员） | 是 | 按审计范围 | 否 |
| 设备健康 | 授权团队 | 是 | 是 | 是 |

## 硬规则

1. 个人明细访问、导出、策略修改、删除全部写入审计日志（含访问者、时间、范围、理由）。
2. 运维权限与内容查看权限分离；Operator 看不到活动内容。
3. 每个 API 端点执行 org/team scope 检查；数据库层可选 RLS。
4. 全员互看禁止；个人明细仅授权角色可见。
5. 导出文件带水印、过期时间与下载审计。
6. AI 报告 v1.0 仅开放给 Company Admin（已确认决策 #11）。
7. 团队汇总达到最小人数（≥5）后才显示匿名聚合。

## 审计事件类型（Phase 2 实现）

登录/登出、策略创建/修改/回滚、个人明细访问、导出、删除/清理作业、模型运行、
设备吊销、角色变更、AI 报告反馈。
