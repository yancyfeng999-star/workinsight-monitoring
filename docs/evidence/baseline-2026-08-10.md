## 修复前失败证据

命令（`apps/api`）：

```bash
npm test
```

结果：失败，`ERR_MODULE_NOT_FOUND`。

```
Error [ERR_MODULE_NOT_FOUND]: Cannot find module
'.../apps/api/src/validate.js' imported from
'.../apps/api/tests/validate.test.ts'
```

原因：`package.json` 的 `test` 脚本为 `node --test tests/*.test.ts`，
Node 无法直接解析 TS 的 `.js` 扩展名导入，缺少 `tsx` loader。
